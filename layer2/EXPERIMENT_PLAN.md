# V3 改进方案与实验冻结范围

2026-11-18。本轮基于上传ZIP独立复核，不将审查报告视为已执行证据。V3是交付版本号，不意味着必须引入一种新算法。

1. 保留FA原评分、丢弃和队列整帧准入；保持FIFO与EDF在统一相对时限下的等价性。统一时限是课程最低实验设置之一，不为分开曲线强行改变主实验。
2. 修复跨平台路径并拒绝路径越界；关键assert改为显式异常；验证只读；缺失值按配对完整样本处理并报告有效n和总n。
3. 写入同文件系统的独立临时目录；审计通过后才重命名发布。输出已存在则拒绝。保留失败临时目录用于诊断，不覆盖旧结果。
4. 独立参考调度器使用逐包队列和有理数评分，穷举多帧、时隙可用性、重传、到达、评分并列及容量，比较每帧结局与完成时刻。另回放旧版171条历史结果，审计完整第二版帧表，重算全部统计量。
5. 新种子3000–3029；固定背景45%、CV=.5、失败概率.1。三组：原始IID，容量4096→40包，其余相同；原始容量、尝试失败改为两状态Markov过程。两项压力因素分别变化，不同时施加。
6. Markov失败状态初始服从稳态p，P(bad|bad)=p+rho(1-p)，P(bad|good)=p(1-rho)，rho=.9。边际失败率仍为p；背景仍IID。调度器不预知未来。参数是示例压力设置，不是实测信道拟合。
7. 每组FIFO、EDF、EDF-safe、FA(0)、FA(1)，各30种子，共450次。主比较FA(1)−FA(0)，另单独报告FA(1)−EDF-safe。压力组与第二基线均属探索性比较；不宣称普遍显著优势。
8. 增加每源完整率、最低完整率、源间极差、重要帧溢出数。普通帧70%底线仅是示例诊断阈值，无标准依据、无保证策略，不据此选α。队列整帧准入对所有策略同等应用；溢出受服务历史影响，不要求策略间拒绝帧相同。

不采用：大规模架构重写、强化学习、PiXR全量复现、凭此次压力结果新调保障参数、补凑文献数量。没有新增外部参考文献，原五项参考材料完整保存在baseline/xr_importance/references。
